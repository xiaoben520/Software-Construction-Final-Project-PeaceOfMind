# 心安·MemoMind — 项目结构与数据存储详解

> 本文档面向不熟悉 C# / WPF 的读者，用尽可能通俗的语言解释每个文件的作用、整体架构，以及数据是如何存储的。

---

## 一、项目总览

**心安·MemoMind** 是一个 **Windows 桌面应用**，使用 **C# + WPF（Windows Presentation Foundation）** 编写。它同时具备以下功能：

- **AI 心灵陪伴**：接入大语言模型（如 DeepSeek、OpenAI），进行共情式对话
- **任务看板**：Todo / Doing / Done 三列管理，支持 AI 语音创建任务
- **赛博植物**：领养虚拟植物，浇水施肥晒太阳养成，植物会用自己的性格和你聊天
- **番茄钟 & 闹钟 & 倒计时**：专注计时器 + 定时提醒
- **文件工作区**：管理常用文件夹和项目路径
- **长期记忆**：AI 自动从对话中提取你的偏好和习惯

---

## 二、三层架构

项目采用经典的 **三层架构 + MVVM 模式**，分为 3 个子项目：

```
┌─────────────────────────────────┐
│  MemoMind.App     (WPF 界面层)   │  用户看到的窗口、按钮、页面
│  - Views          (UI 布局)     │  
│  - ViewModels     (业务逻辑)    │  
│  - Services       (应用服务)    │  
├─────────────────────────────────┤
│  MemoMind.Core    (核心定义层)   │  纯抽象，不依赖任何其他项目
│  - Interfaces     (接口契约)    │  定义"能做什么"
│  - Models         (数据模型)    │  定义"数据长什么样"
├─────────────────────────────────┤
│  MemoMind.Infrastructure (实现层)│  数据库访问 + 接口的具体实现
│  - Data           (EF Core)    │  
│  - Services       (数据库操作)  │  
│  - Migrations     (数据库迁移)  │  
└─────────────────────────────────┘
```

**依赖方向**：`App → Core ← Infrastructure`（Core 在最中间，不依赖任何人）

## 七、数据存储详解

### 7.1 存储位置

所有用户数据存储在本机的 `%LocalAppData%\MemoMind\` 目录下，即：

```
C:\Users\<你的用户名>\AppData\Local\MemoMind\
```

该目录在 `App.xaml.cs` 的第 34 行创建：

```csharp
var appDataFolder = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData),
    "MemoMind");
Directory.CreateDirectory(appDataFolder);
```

### 7.2 两种存储方式

项目使用 **两种存储方式**：

| 方式 | 文件 | 存储内容 |
|---|---|---|
| **SQLite 数据库** | `MemoMind.db` | 任务、聊天历史、记忆、文件工作区、植物配置、日历事件、番茄钟记录 |
| **JSON 文件** | 多个 `.json` 文件 | 用户设置、最近文件、闹钟、植物状态、植物自定义覆盖 |

### 7.3 SQLite 数据库（MemoMind.db）

使用 **Entity Framework Core + SQLite** 存储结构化数据。数据库包含 **8 张表**，每张表的主键 `Id` 都是自增整数：

#### Tasks（任务表）

| 列名 | 类型 | 说明 |

| Id | INTEGER (PK) | 自增主键 |
| Title | TEXT | 任务标题 |

| IsUrgent | INTEGER | 是否紧急（0/1） |
| Status | TEXT | 状态：Todo / Doing / Done |
| StartDate | TEXT | 开始日期（可为空） |
| DueDate | TEXT | 截止日期（可为空） |
| CreatedAt | TEXT | 创建时间 |
| CompletedAt | TEXT | 完成时间（可为空） |
| SourceType | TEXT | 来源：Manual（手动）/ Agent（AI创建）/ Seed（示例数据） |

#### ChatMessages（聊天消息表）

| 列名 | 类型 | 说明 |
|---|---|---|
| Id | INTEGER (PK) | 自增主键 |
| Sender | TEXT | 发送者：我 / MemoMind / 系统 |
| Content | TEXT | 消息内容 |

| IsUserMessage | INTEGER | 是否为用户消息（0/1） |

#### Memories（记忆表）

### 7.4 JSON 文件

| 文件 | 负责读写的类 | 存储内容 |
|---|---|---|
| `settings.json` | `JsonAppSettingsStore` | 用户设置：API Key、Base URL、模型名、AI 人设、主题、声音开关、页面布局等 |
| `file_workspace_state.json` | `FileWorkspaceStateService` | 最近打开的文件/文件夹列表 + 工作区分组配置 |
| `alarms.json` | `PomodoroAlarmViewModel` | 所有闹钟的列表（名称、时间、重复模式、启用星期） |
| `cyber_plant.json` | `CyberPlantViewModel` | 植物当前完整状态（类型、名称、各属性值、生长等级、心情、聊天记录等） |
| `plant_profiles.json` | `CyberPlantViewModel` | 用户对预设植物的自定义覆盖（改名、改提示词、改图片、隐藏/恢复） |

### 7.5 为什么有些数据存数据库，有些存 JSON？

| 存 SQLite | 存 JSON |
|---|---|
| 结构化、需要查询和筛选的数据 | 键值对、配置类数据 |
| 数据量可能较大（聊天记录、任务） | 数据量小、每次整体读写 |
| 需要关联查询 | 无需关联 |
| 例子：任务、消息、记忆 | 例子：设置、闹钟、植物状态 |

## 八、关键运行时流程

### 8.1 启动流程

```
App.OnStartup()
  → 创建 %LocalAppData%\MemoMind\ 目录
  → 注册所有服务到依赖注入容器
  → 应用用户保存的主题
  → 自动运行数据库迁移（建表/升级）
  → 如果 Tasks 表为空，插入两条示例任务
  → 创建并显示 MainWindow
```

### 8.2 页面切换流程

```
用户点击侧边栏按钮
  → MainViewModel.NavigateTo("task-board")
  → 找到对应的 ViewModel
  → 更新 CurrentPageViewModel 属性
  → WPF DataTemplate 自动匹配 ViewModel → View
  → UI 自动刷新
```

### 8.3 AI 对话流程

```
用户输入消息
  → ChatViewModel.Send()
  → 加载历史消息 + AI 记忆
  → ChatService.SendAgentAsync()
  → 构建 System Prompt（用户人设 + 记忆 + 历史 + 工具定义）
  → HTTP POST 到 AI API（OpenAI 兼容格式）
  → 如果 AI 调用 create_task → AgentToolExecutor → TaskService → SQLite
  → AI 返回最终回复 → 显示在界面
  → 后台异步提取长期记忆 → MemoryService → SQLite
```
