# 心安·MemoMind 系统设计文档

## 1. 系统概述

随着大学生学习压力、时间管理压力和情绪波动问题逐渐增多，单纯的任务管理工具已经无法满足“事务管理 + 情绪支持”的复合需求。许多学生在面对作业、考试、小组讨论、实习安排等事项时，既需要一个清晰的待办系统，也需要一个能理解情绪、温和提醒和陪伴式反馈的工具。

“心安·MemoMind”是一个基于 C# 和 WPF 的 Windows 桌面应用，面向大学生的学习与情绪支持场景。项目采用本地优先、模块可扩展的设计思路，核心目标是把任务管理、AI 聊天陪伴、文件工作区和个性化设置整合到一个统一界面中。

当前项目可以实现“页面可扩展、导航可配置、主页可组合”：

- 左侧导航栏用于切换页面，并可在设置中控制显示哪些页面。
- 主页以模块卡片方式呈现，可在设置中控制显示哪些模块。
- 新页面新增时，只需补充页面定义、视图模型和视图，即可快速接入主界面。

## 2. 总体架构

### 2.1 技术架构

- 表现层：WPF
- 架构模式：MVVM
- 核心层：业务接口、页面定义、通用状态与导航模型
- 基础设施层：SQLite、EF Core、本地配置、文件系统访问、AI 接入预留
- 测试层：单元测试与基础功能测试

### 2.2 分层说明

1. UI 层（MemoMind.App）
   - 负责页面展示、导航切换、命令绑定和样式资源。
   - 主要页面包括主页、任务看板、AI 聊天、文件工作区、设置页。

2. 核心层（MemoMind.Core）
   - 定义任务、文件工作区等领域接口与基础模型。
   - 统一业务规则，避免 UI 与数据库实现耦合。

3. 基础设施层（MemoMind.Infrastructure）
   - 负责 SQLite 数据访问、EF Core 迁移、本地存储、外部服务适配。

4. 测试层（MemoMind.Tests）
   - 验证任务增删改查、文件工作区、设置保存等关键流程。

## 3. 模块设计

### 3.1 页面与导航模块

系统采用“左侧导航栏 + 右侧内容区”的主界面布局：

- 左侧导航栏：展示当前启用的页面，如主页、任务看板、AI 聊天、文件工作区、设置。
- 右侧内容区：显示当前页面对应的视图内容。
- 主页：以卡片模块形式展示可跳转的功能入口。
- 设置页：支持配置左侧栏和主页中显示的页面。

页面接入规则：

1. 定义页面标识、标题、描述和默认可见性。
2. 注册对应的 ViewModel。
3. 通过内容模板或绑定机制自动显示对应视图。
4. 在设置页中勾选是否显示在左侧栏和主页。

### 3.2 任务看板模块

任务看板是当前项目的核心事务模块，用于管理学习、作业和待办事项。

功能包括：

- 新增任务
- 编辑任务
- 删除任务
- 任务状态管理（待办、进行中、已完成）
- 截止日期与优先级设置
- 按时间顺序展示任务列表

设计原则：

- 以“轻量任务清单”为主，不强制复杂项目管理能力。
- 后续若需要番茄钟、进度条或任务拆解，可作为扩展页面接入。

### 3.3 AI 聊天模块

AI 聊天模块用于提供陪伴式对话、学习建议和任务识别能力。

功能包括：

- 用户输入自然语言内容
- AI 返回回复、建议或结构化任务信息
- 支持将对话中提取出的待办事项转为任务
- 支持情绪安抚、学习鼓励和规划建议

设计原则：

- AI 功能可选启用；没有 API Key 时，基础应用仍可使用。
- AI 输出尽量采用结构化格式，方便后续扩展解析。

### 3.4 文件工作区模块

文件工作区用于管理学习资料、项目目录和常用文件路径。

功能包括：

- 保存文件夹或文件路径
- 管理常用工作区列表
- 一键打开文件或文件夹
- 记录最近访问时间

设计原则：

- 以本地路径为主，不依赖云同步。
- 允许用户快速建立课程资料和项目目录入口。

### 3.5 设置与扩展模块

设置页用于系统配置和页面开关管理。

功能包括：

- 保存 AI API Key
- 切换主题
- 配置提醒开关与基础偏好
- 控制左侧导航栏显示哪些页面
- 控制主页显示哪些模块

设计原则：

- 主页与导航不写死，页面展示由配置驱动。
- 后续新增“番茄钟”“赛博植物”等页面时，只需接入页面目录并在设置中勾选即可。

### 3.6 预留扩展模块

为保证项目后续可扩展，系统预留以下模块接入方式，但不作为当前核心必做内容：

- 番茄钟
- 赛博植物
- 周报统计
- 情绪曲线
- 其他个性化小组件

这些模块后续可通过新增页面定义、视图模型和视图的方式接入，不需要重构主窗口。

## 4. 数据库设计

系统采用 SQLite 作为本地数据库。当前项目只保留核心数据表，删除不必要的日历、情绪统计和番茄钟明细表，减少设计复杂度。

### 4.1 Tasks 表

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | int | 主键 |
| Title | text | 任务标题 |
| Description | text | 任务描述 |
| Status | text | 任务状态 |
| Priority | int | 优先级 |
| DueDate | datetime | 截止时间 |
| CreatedAt | datetime | 创建时间 |
| CompletedAt | datetime | 完成时间 |
| SourceType | text | 手动或 AI |

### 4.2 FileWorkspaces 表

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | int | 主键 |
| DisplayName | text | 显示名称 |
| Path | text | 文件或文件夹路径 |
| LastOpenedAt | datetime | 最近打开时间 |
| CreatedAt | datetime | 创建时间 |

### 4.3 AppSettings 表

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | int | 主键 |
| SettingKey | text | 配置键 |
| SettingValue | text | 配置值 |
| UpdatedAt | datetime | 更新时间 |

### 4.4 PageLayout 表

用于保存页面可见性配置，支持左侧栏和主页的动态调整。

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | int | 主键 |
| LayoutKey | text | 配置类别，如 Sidebar 或 Home |
| PageId | text | 页面标识 |
| IsVisible | bool | 是否显示 |
| UpdatedAt | datetime | 更新时间 |

### 4.5 ChatSessions 表（可选）

如果后续需要保存 AI 对话历史，可增加该表。

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | int | 主键 |
| SessionTitle | text | 会话标题 |
| CreatedAt | datetime | 创建时间 |
| UpdatedAt | datetime | 更新时间 |

### 4.6 ChatMessages 表（可选）

如果后续需要保存聊天记录，可增加该表。

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | int | 主键 |
| SessionId | int | 所属会话 |
| Sender | text | 发送者 |
| Content | text | 内容 |
| CreatedAt | datetime | 创建时间 |

> 说明：CalendarEvents、EmotionLogs、PomodoroSessions 等表在当前版本中不作为核心必需表，后续若真正实现对应模块再补充即可。

## 5. 核心流程设计

### 5.1 启动流程

1. 应用启动后读取本地设置。
2. 加载页面目录与可见性配置。
3. 初始化左侧导航栏和主页模块。
4. 进入默认页面。

### 5.2 页面切换流程

1. 用户点击左侧导航栏按钮。
2. 主窗口根据页面标识切换右侧内容。
3. 页面视图模型接管当前界面逻辑。

### 5.3 主页模块跳转流程

1. 主页以模块卡片展示可用页面。
2. 用户点击“打开模块”。
3. 系统跳转到对应页面。

### 5.4 设置保存流程

1. 用户在设置中修改主题、API Key 和页面可见性。
2. 系统保存通用设置与页面布局配置。
3. 左侧栏和主页模块立即更新。

### 5.5 任务管理流程

1. 用户新增或编辑任务。
2. 系统写入本地数据库。
3. 任务列表自动刷新。

### 5.6 AI 交互流程

1. 用户输入自然语言内容。
2. 系统拼接提示词并调用 AI 接口。
3. AI 返回建议或结构化结果。
4. 系统按结果更新任务或提示用户。

### 5.6.1 主业务流程

1. 用户录入需求
- 手动创建任务，或通过 AI 对话输入学习计划。

2. 系统结构化处理
- 将输入解析为任务项（标题、截止时间、备注）。

3. 制定执行计划
- 用户在任务看板中对任务进行修改和状态管理。

4. 执行与记录
- 用户处理任务并在系统中更新状态；
- 后续扩展模块可接入专注记录、打卡或小组件能力。

5. 反馈与复盘
- 当日结束后可生成简要统计（完成任务数、情绪反馈、扩展模块数据）；
- AI 给出次日建议（先做高优先级、拆分大任务等）。


### 5.6.2 页面配置流程（与系统设计文档一致）

1. 用户进入设置页，勾选左侧导航栏显示页面。  
2. 用户勾选主页模块显示页面。  
3. 系统实时更新左侧导航与主页卡片。  
4. 用户保存后写入本地配置，下次启动自动恢复。

## 6. 关键类设计

### 6.1 页面与导航相关

- `AppPageDefinition`：页面定义信息。
- `AppPageCatalog`：页面目录注册表。
- `NavigationPageItemViewModel`：页面导航项状态。
- `MainViewModel`：统一管理页面切换与布局配置。

### 6.2 功能页面相关

- `HomeViewModel`：主页模块展示与跳转。
- `TaskBoardViewModel`：任务看板逻辑。
- `ChatViewModel`：聊天交互逻辑。
- `FileWorkspaceViewModel`：文件工作区逻辑。
- `SettingsViewModel`：系统设置与页面可见性控制。

### 6.3 数据模型相关

- `TaskItem`
- `FileWorkspace`
- `UserSettings`
- `ChatMessage`

## 7. 接口与扩展约定

### 7.1 页面扩展约定

新增页面时建议遵循以下约定：

1. 在页面目录中注册页面定义。
2. 增加对应的 ViewModel。
3. 增加对应的 View。
4. 在设置页中默认允许用户选择是否显示。

### 7.2 数据访问约定

- 任务、文件工作区和设置数据全部优先本地存储。
- AI 对话历史和扩展模块数据采用“按需增加表”的方式处理。
- 非核心模块不要强行加入主数据库结构。
