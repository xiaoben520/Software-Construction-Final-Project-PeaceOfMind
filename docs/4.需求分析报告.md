# 心安·MemoMind 需求分析报告

## 1. 项目背景

随着大学生学习压力、时间管理压力和情绪波动问题逐渐增多，单纯的任务管理工具已经无法满足“事务管理 + 情绪支持”的复合需求。许多学生在面对作业、考试、小组讨论、实习安排等事项时，既需要一个清晰的待办系统，也需要一个能理解情绪、温和提醒和陪伴式反馈的工具。

“心安·MemoMind”希望在 Windows 桌面端提供一种轻量、稳定、可长期使用的解决方案，让用户在记录任务的同时，也能获得情绪上的整理与支持。

## 2. 项目目标

本项目旨在实现一个以 C# 为主的 Windows 窗口应用，完成以下目标：

- 提供任务管理、日历、番茄钟、文件工作区等基础事务功能。
- 提供 AI 聊天陪伴、情绪识别、任务提取、周报生成等智能功能。
- 支持无 AI 模式下的基础运行，保证应用可用性。
- 形成适合课程设计、团队协作和展示答辩的完整项目架构。

## 3. 用户画像

### 3.1 主要用户

- 大学生，尤其是课程任务较多、时间管理压力大的用户。
- 有情绪倾诉、整理心事、记录计划需求的用户。
- 需要本地化、低门槛、桌面端工具的用户。

### 3.2 用户特征

- 经常面对作业、DDL、考试、小组讨论等任务。
- 需要同时管理学习资料、项目文件、备忘事项。
- 偏好简单直接、界面清晰、提醒友好的工具。
- 对“压力大时的陪伴式反馈”有明确需求。

## 4. 问题分析

当前用户常见痛点包括：

- 任务记录分散在多个平台，难以统一管理。
- 待办事项容易遗漏，优先级不清晰。
- 情绪问题与事务管理分离，缺少整体支持。
- 学习文件、项目文件和备忘内容分布混乱。
- 传统提醒过于强硬，容易造成反感和压力。

## 5. 竞品与对比分析

### 5.1 竞品类型

- **纯任务管理工具**：如待办清单、日历类应用。
- **效率工具**：如番茄钟、专注类软件。
- **AI 聊天工具**：偏向对话陪伴，但缺少事务管理能力。
- **笔记工具**：适合记录，但缺少任务自动识别和提醒机制。

### 5.2 竞品不足

- 任务管理与情绪支持割裂。
- 很多工具只适合记录，不适合主动整理和推荐。
- AI 聊天工具通常缺乏本地事务闭环。
- 提醒策略常较生硬，不符合“温和支持”的场景。

### 5.3 本项目差异化

- 将“心理支持”与“事务管理”融合到一个桌面端系统。
- 支持自然语言输入，自动识别任务与情绪。
- 同时保留无 AI 可用的基础功能，降低使用门槛。
- 采用温和提醒和周报反馈，让用户持续获得正向激励。

## 6. 功能需求分析

### 6.1 核心功能需求

1. **每日任务管理**
   - 新增、编辑、删除、完成任务。
   - 按日期、优先级、状态筛选任务。

2. **日历功能**
   - 展示日程安排。
   - 支持任务与具体日期、时间关联。

3. **番茄钟功能**
   - 支持计时、暂停、重置。
   - 记录专注时长与任务关联。

4. **AI 智能识别任务**
   - 识别自然语言中的任务内容、截止时间、情绪。
   - 自动写入任务或日历。

5. **文件管理系统**
   - 管理常用文件路径。
   - 一键打开工作区文件或文件夹。

6. **设置系统**
   - API Key 保存。
   - 主题与提醒偏好设置。
   - 默认路径设置。

### 6.2 可选功能需求

1. **任务拆解**
   - 将模糊目标拆成可执行步骤。

2. **温和提醒**
   - 使用鼓励式语言提醒用户开始行动。

3. **优先级排序**
   - 根据日期、重要度、精力状态推荐今日重点事项。

4. **情绪疏导**
   - 当用户表达负面情绪时，给出共情与安抚反馈。

5. **进度追踪与周报**
   - 统计完成率、情绪变化、专注时长。
   - 每周生成总结和鼓励性反馈。

## 7. 非功能需求

### 7.1 可用性

- 没有 AI 接口时，基础功能仍能正常使用。
- 操作路径尽量短，减少复杂配置。

### 7.2 性能

- 本地任务列表、文件列表和日历切换应保持流畅。
- AI 请求失败时应快速回退，不阻塞主界面。

### 7.3 可维护性

- 采用 MVVM 和分层结构，便于团队分工。
- 核心逻辑与界面分离，便于后续扩展。

### 7.4 安全性

- API Key 不应明文写死在代码中。
- 用户数据优先保存在本地，减少外部依赖。

## 8. 功能优先级

### 8.1 必做功能

- 任务管理
- 日历事项
- 番茄钟
- 文件工作区
- 设置
- AI 聊天基础接入

### 8.2 加分功能

- AI 任务提取
- 情绪识别
- 周报生成
- 温和提醒
- 任务拆解
- 优先级推荐

## 9. 需求范围说明

### 9.1 本期范围内

- Windows 桌面端应用。
- 本地数据库与本地配置。
- AI 功能可选启用。
- 团队课程项目展示所需的主要功能。

### 9.2 暂不展开

- 跨平台移动端适配。
- 完整云端同步系统。
- 大规模多人协作后台。
- 复杂社交功能。

## 10. 结论

“心安·MemoMind”不是单一的效率工具，而是一个面向大学生的“事务管理 + 心理陪伴”桌面系统。它的价值在于：

- 帮助用户理清任务。
- 缓解情绪压力。
- 提升执行力与专注度。
- 让用户感受到被理解、被支持、被鼓励。
